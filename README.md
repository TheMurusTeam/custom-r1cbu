# R1CBU 1KO125
This is a custom modification of the Xiegu X6100 R1CBU firmware that I developed for my personal use. Feel free to test it out!
The purpose of this firmware is to add new SWL-oriented features to R1CBU while preserving all of its original functionality. It is based on R1CBU firmware version 0.34.2 by gdyuldin, available [here](https://github.com/gdyuldin/x6100_gui/releases)

Enjoy!
