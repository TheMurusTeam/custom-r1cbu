# 1KO125 firmware for Xiegu X6100
This is a custom modification of the Xiegu X6100 R1CBU firmware that I developed for my personal use. Feel free to test it out!
The purpose of this firmware is to add new features to R1CBU while preserving all of its original functionality. It is based on R1CBU/OpenX6100 firmware by gdyuldin, available [here](https://github.com/OpenX6100/x6100_gui/releases)

Enjoy!

Hany El Imam 1KO125
