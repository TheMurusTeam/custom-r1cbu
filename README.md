# 1KO125 firmware for Xiegu X6100

> **This repository is no longer maintained.**
> 1KO125 is now developed, with its full source code, at
> **https://github.com/TheMurusTeam/x6100_gui** (branch `1ko125`).
> New releases and SD card images are published there.

The releases here (up to 1.0.2 beta 5) stay available as they were, each
with its SD card image and its source archive (`...-src.tar.gz`).
